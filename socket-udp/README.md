# Socket UDP — Atividade 02

- [Questão 1](questao-01/README.md): chat P2P por UDP, com lista de participantes por TCP.
- [Questão 2](questao-02/README.md): upload UDP em blocos de 1024 bytes, com SHA-1.

Como na Atividade 01, o servidor está em Java 17 e o cliente em Node.js 18+, sem dependências externas. Na Questão 1, o servidor TCP apenas informa quem está online: as mensagens seguem diretamente de um cliente ao outro por UDP.
