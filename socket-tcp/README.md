# Socket TCP — Atividade 01

- [Questão 1](questao-01/README.md): servidor de navegação em diretórios, com autenticação e múltiplos clientes. Implementada.
- [Questão 2](questao-02/README.md): gerenciamento remoto de arquivos com protocolo binário. Implementada.

Baseado no PDF `Atividade 01 - TCP - v2.pdf` fornecido com a atividade.

Em ambas as questões, o servidor está em **Java 17** e o cliente em **JavaScript/Node.js**. Isso permite demonstrar a comunicação entre duas linguagens, como pede a descrição geral. Você pode rodar os dois programas sozinho, em terminais separados.
